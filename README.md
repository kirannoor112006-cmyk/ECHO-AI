# 🔎 ECHO // AI — Interactive Mystery Investigation

**ECHO // AI** is an AI-powered mystery investigation application built with Python and Streamlit. It allows users to investigate a fictional case, explore clues, question suspects, and submit their final verdict.

## ✨ Features

- 🕵️ Interactive fictional mystery case
- 👥 Multiple suspects to interrogate
- 💬 AI-generated suspect responses using Google Gemini
- 🧩 Interactive evidence board
- ⚖️ Final verdict submission
- 🌙 Dark, futuristic user interface

## 🛠️ Technologies Used

- **Python** — Application logic
- **Streamlit** — Web interface
- **Google Gemini API** — AI-powered suspect conversations
- **GitHub** — Source code management

## 🚀 How It Works

1. Open the mystery investigation.
2. Select a suspect.
3. Ask questions and analyze their responses.
4. Explore the available clues.
5. Submit your final verdict.

## ⚙️ Setup

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Configure your Gemini API key using Streamlit Secrets:

```toml
GEMINI_API_KEY = "your_api_key_here"
```

Run the application:

```bash
streamlit run app.py
```

## 🔐 Security

Never publish your API key in source code or commit it to a public repository.
